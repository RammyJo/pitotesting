# Seven Perfume V8.1 — Broken Page Fix

This is a targeted repair of V8 page-based navigation.

Fixed:
- `#/home` is now treated as the home page.
- Product-detail Add to Cart / Buy Now actions work through the single delegated route handler instead of accumulating listeners on every product visit.
- Catalog loading now has a visible loading state.
- If `/api/catalog` is temporarily unavailable, the storefront falls back to the embedded TEST catalog so the site does not render blank.
- Added a 10-second API timeout and retry-on-error.
- Favorites localStorage errors no longer break the site.
- Cart persists through a refresh in the browser.
- Added a JS-disabled fallback message.
- Added simple error/loading presentation styles.

No product prices, shipping assumptions, checkout structure, or order validation rules were changed.
