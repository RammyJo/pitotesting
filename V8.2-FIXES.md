# Seven Perfume V8.2 Fixes

Fixed the blank homepage issue caused by stale cart data from older versions.

- Older localStorage carts used a different data shape and crashed `renderCart()` before the first page could render.
- V8.2 ignores malformed/legacy cart entries and only restores the current `{ productId, sizeId, quantity }` format.
- Cart items are validated against the live catalog before rendering.
- JavaScript and CSS URLs are cache-busted with `?v=8.2`.
- Local development now sends no-cache headers for JS/CSS so old browser code cannot remain stuck.
- A runtime-error fallback prevents a totally blank screen.
