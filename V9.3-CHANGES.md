# Seven Perfume V9.3

## Fixes
- Fixed View Details by giving it an explicit `data-route="product"` and `data-route-id` rather than relying on the older `data-action="quick"` product-card handler.
- Removed the delayed route DOM swap. Destination pages now render immediately, then use the short page-entry animation. Scroll reset is instant so it no longer looks like a scroll through the old page.
- Added clickable Instagram and Facebook icons to the standard footer, using the exact official URLs supplied. Links open in a new tab with `noopener noreferrer`.
- Updated CSS and JavaScript asset cache versions to `9.3`.

## Check before release
- Run the syntax and package checks listed in this project.
- Test View Details from both Shop and featured homepage cards. Confirm the address becomes `#/product/<product-id>` and the selected fragrance name appears.
- Click both footer icons and confirm they open the supplied Instagram and Facebook pages.
- Test on a physical phone after deployment.

## Limitations
- This package has not been deployed to Cloudflare from this environment.
- The browser visual test is not certified; use a real browser after deploying.
- This is still a test-mode commerce build; PayMongo and real courier APIs are not connected.
